## 작업 요약

issue-start / issue-end / issue-merge 의 다음 행동 선택지에서 "다른 이슈 착수" 제안을
**남은 열린 이슈가 있을 때만** 하도록 세 스킬의 규칙 문구를 통일했습니다.
열린 이슈가 0건이면 권장 위치만 바꾸는 것이 아니라 선택지 자체를 제외합니다.

## 증거 생략 사유

스킬 지침 마크다운 3개 파일만 수정한 문서 전용 변경이라 화면 캡처·성능 측정이 의미가
없습니다. 대신 변경 전후 원문 발췌를 `.issue/89/evidence/{before,after}/` 에 남겼습니다.

## 변경 전후

**issue-end** (`references/next-actions.md`) — 기존에는 권장 위치만 바꿔 선택지가 그대로 노출됨

```diff
-- 열린 이슈가 없으면 1번 대신 3번을 권장으로 올린다.
+- 남은 열린 이슈가 하나도 없으면 1번(다른 이슈 착수)을 선택지에서 빼고 3번을 권장으로 올린다. 다른 이슈 착수는 남은 열린 이슈가 있을 때만 제안한다.
```

**issue-start** (`references/next-actions.md`) — 기존에는 열린 이슈 유무 조건이 없었음

```diff
 - 검증 명령이 실패한 채로 왔으면 2번을 권장으로 올린다. **실패를 덮은 채 PR 로 넘기지 않는다.**
+- 현재 이슈를 제외한 남은 열린 이슈가 하나도 없으면 3번(다른 이슈 착수)을 선택지에서 뺀다. 다른 이슈 착수는 남은 열린 이슈가 있을 때만 제안한다.
 - 그 외에는 1번이 권장이다.
```

**issue-merge** (`references/next-actions.md`) — 기존 제외 규칙을 표준 문구로 정렬

```diff
-- 열린 이슈가 하나도 없으면 1번을 빼고 3번을 권장으로 올린다.
+- 남은 열린 이슈가 하나도 없으면 1번(다른 이슈 착수)을 선택지에서 빼고 3번을 권장으로 올린다. 다른 이슈 착수는 남은 열린 이슈가 있을 때만 제안한다.
```
