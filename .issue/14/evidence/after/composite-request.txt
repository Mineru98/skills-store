요청      : 대시보드에 기간 필터 넣고, 주문 목록 가끔 비는 것도 고치고, 안 쓰는 export 스크립트도 지워줘. 셋 다 이번 스프린트에 해야 하는 것들이야   (before 와 동일)

----- 스킬 응답 -----
요청이 "기능 추가 + 버그 수정 + 코드 삭제" 복합 변경이라 `issue-create` 흐름을 탔습니다. 다만 실행이 중간에 막혔습니다.

## 막힌 지점

- `git rev-parse` 는 통과 — git 저장소 맞습니다 (`.../scratchpad/trigger-fixture`)
- `gh auth status`, `issue-create.mjs gate`, 파일 목록 조회(`ls`, `find`) 는 **권한 승인이 거부**되어 실행하지 못했습니다

그래서 성숙도 게이트 판정, 유사 이슈 중복 검사, 코드베이스 대조는 하지 못했습니다. 스킬 규칙대로 **이슈를 등록하지 않고 초안까지만** 남깁니다.

## 분할안 (독립성 테스트 통과 — 3건)

| # | 제목 | 요약 | 예상 라벨 | 성격 |
|---|------|------|-----------|------|
| 1 | 대시보드 기간 필터 추가 | 대시보드에 조회 기간을 선택하는 필터 UI와 질의 연동 | `enhancement` | frontend + backend |
| 2 | 주문 목록 간헐적 빈 렌더링 수정 | 주문 목록이 가끔 빈 상태로 표시되는 문제 | `bug` | 재현 정보 필요 |
| 3 | 미사용 export 스크립트 제거 | 참조되지 않는 레거시 export 스크립트 삭제 | `chore` | backend |

셋 다 따로 머지 가능하고, 완료 기준이 겹치지 않고, 하나가 취소돼도 나머지가 성립하고, 라벨 성격이 갈립니다 → 이슈 3개로 분리가 맞습니다.

## 초안에서 비어 있는 칸

코드베이스를 못 읽어서 아래는 채우지 못했습니다. 이슈 본문의 재현 절차·범위 항목이 비면 `issue-start` 의 대조 분석이 헛돌기 때문에 중요합니다.

- **#2** — 어떤 화면/API 인지, "가끔"의 조건(페이지네이션? 필터 초기화? 새로고침 직후?), 콘솔 에러 유무
- **#3** — 삭제 대상 스크립트의 실제 경로
- **#1** — 기간 프리셋 범위(오늘/7일/30일/직접 지정 등)와 기본값

## 다음으로 뭐 할까요

1. **권한을 열어주시면** — `gh`, `ls`/`find`, 스킬 스크립트 실행을 허용해 주시면 게이트 → 중복 검사 → 초안 → 등록까지 그대로 이어서 진행합니다
2. **위 3건 분할안이 맞는지** 알려주시고, 비어 있는 칸(특히 #2 재현 조건, #3 스크립트 경로)을 채워주시면 초안 전문을 작성해 승인받고 등록하겠습니다

어느 쪽으로 갈지 알려주세요.
