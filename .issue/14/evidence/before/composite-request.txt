----- 스킬 응답 -----
코드베이스와 전제를 먼저 확인했고, 이슈 등록 전에 짚어야 할 게 두 가지 나왔습니다.

## 확인된 상태

**1. 저장소가 아직 스캐폴딩 단계입니다.** 추적 중인 소스 15개가 전부 빈 스텁입니다.

```
src/presentation/features/dashboardView.tsx  → return <div />
src/presentation/features/orderListView.tsx  → return <div />
src/application/hooks/api/useOrderList.ts    → ({ data: null, isLoading: false })
src/infrastructure/api/order.ts              → return null  (+ "// change 1~34" 주석만)
```

커밋 34개가 전부 `feat: 변경 N` 형식의 주석 추가입니다. 즉 "주문 목록이 가끔 빈다"는 현상은 현재 코드에서는 재현할 대상이 없습니다 — `useOrderList`가 항상 `data: null`을 반환하니 **가끔이 아니라 항상 비어 있는** 상태입니다.

**2. 지울 export 스크립트가 저장소에 없습니다.** `git ls-files` 전체와 미추적 파일(`.claude/`, `.omc/`)을 봐도 export 관련 파일이 존재하지 않습니다.

**3. 실행 권한이 막혀 있습니다.** `gh auth status`, `command -v gh`, 스킬의 `issue-create.mjs` 실행이 모두 승인 거부로 차단됐습니다. 그래서 중복 이슈 검색과 실제 `gh issue create`를 수행할 수 없습니다.

## 그래서 지금 드릴 수 있는 것 — 이슈 초안 3건

세 건 모두 "이번 스프린트" 요청이라 하나로 묶지 않고 별도 이슈로 나눴습니다.

### #A `feat` · 대시보드 기간 필터 추가

**성격**: frontend + backend (both)

**배경**: 대시보드가 현재 기간 구분 없이 단일 집계만 노출한다.

**요구**: 대시보드 상단에 기간 선택 UI를 추가하고, 선택된 기간이 요약 조회에 반영되게 한다.

**대상 파일**
- `src/presentation/features/dashboardView.tsx` — 기간 선택 UI
- `src/application/hooks/api/useDashboardSummary.ts` — 기간 파라미터 수용
- `src/infrastructure/api/dashboard.ts` — `fetchdashboard`에 기간 인자 추가

**미결 사항 (착수 전 확정 필요)**
- 프리셋 범위: 오늘 / 7일 / 30일 / 사용자 지정 중 무엇까지?
- 기본 선택값은?
- 선택 상태를 URL 쿼리에 유지하나?

**라벨**: `enhancement`, `frontend`, `backend`

---

### #B `bug` · 주문 목록이 비어 보이는 문제

**성격**: 현재 코드 기준으로는 backend/data 계층

**현상 (사용자 보고)**: 주문 목록이 가끔 빈 상태로 뜬다.

**코드 확인 결과**: `useOrderList`가 무조건 `{ data: null, isLoading: false }`를 반환하고 `fetchorder()`는 `null`을 반환한다. 실제 구현이 아직 없어서 보고된 "가끔"과 코드 상태가 일치하지 않는다.

**착수 전 확인 필요**
- 이 현상이 관찰된 환경이 이 저장소가 맞나, 아니면 배포된 다른 브랜치/버전인가?
- 빈 목록일 때 에러 토스트나 콘솔 로그가 같이 뜨나? (로딩 레이스 vs 조회 실패 구분용)
- 재현 빈도와 조건 (특정 계정 / 특정 필터 / 새로고침 직후 등)

**라벨**: `bug`, `needs-repro`

---

### #C `chore` · 미사용 export 스크립트 제거

**성격**: 코드 삭제

**문제**: 저장소에서 export 스크립트를 찾지 못했다. `package.json` 스크립트는 `dev` / `build` / `lint` 셋뿐이고, 추적 파일 15개 중 해당하는 것이 없다.

**착수 전 확인 필요**: 삭제 대상의 정확한 경로 또는 파일명.

**라벨**: `chore`, `blocked`

## 다음 단계 — 확인 부탁드립니다

1. **#B와 #C는 전제가 비어 있습니다.** #B는 재현 환경, #C는 삭제할 파일 경로를 알려주시면 초안을 채워 넣겠습니다. 지금 그대로 등록하면 착수 단계에서 다시 멈춥니다.
2. **저장소 성숙도**: 전부 스텁인 상태라 이슈 트래킹보다 구현이 먼저일 수도 있습니다. 그래도 스프린트 관리 목적으로 3건 등록을 원하시면 그대로 진행하겠습니다.
3. **`gh` 실행 권한**: 실제 등록에는 `gh` 명령 승인이 필요합니다. 승인해 주시면 중복 검사부터 등록까지 이어서 하겠습니다.
