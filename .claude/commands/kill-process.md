$ARGUMENTS: 포트 번호 (하나 또는 여러 개, 공백/쉼표로 구분. e.g. 3000 또는 3000 8080 5173)

`$ARGUMENTS`에 지정된 각 포트에서 실행 중인 프로세스를 찾아서 종료해줘.

다음 순서로 각 포트마다 진행해:

1. `lsof -ti :<port>` 명령으로 해당 포트를 사용하는 프로세스 PID를 찾아줘
2. PID가 있으면 `kill -9 <PID>` 로 프로세스를 종료해줘
3. PID가 없으면 "포트 <port>에서 실행 중인 프로세스가 없습니다"라고 알려줘
4. 종료 후 해당 포트가 정상적으로 비워졌는지 확인해줘

여러 포트가 지정된 경우 각 포트의 결과를 개별적으로 보고해줘.
