# 프론트엔드 이슈 대조 분석

## 1. 화면에서 코드로 좁히기

스크린샷과 본문에서 얻은 단서 순으로 검색한다.

```bash
# 화면에 보이는 문구로 시작하는 것이 가장 빠르다
rg -n "주문 목록" --type-add 'ui:*.{tsx,jsx,vue,svelte,ts}' -tui
# i18n 을 쓰면 키를 먼저 찾고 그 키의 사용처를 찾는다
rg -n "orders.list.title" -g '!node_modules'
# URL 경로로 라우트 진입점 찾기
rg -n "orders" --glob '{app,pages,src/routes}/**'
```

찾은 뒤 위에서 아래로 훑는다. 라우트 → Feature/컨테이너 → 컴포넌트 → 스타일 → 상태/훅.

## 2. 채워야 할 조사 항목

```text
진입점        라우트 파일과 컨테이너 컴포넌트 (path:line)
렌더 경로      문제가 보이는 마크업을 실제로 그리는 컴포넌트
상태 출처      로컬 state / 전역 스토어 / 서버 상태 중 어디서 오는가
스타일 출처    조건부 클래스·styled 조건식·테마 토큰
데이터 계약    화면이 기대하는 필드와 API 응답의 차이
재사용 범위    같은 컴포넌트를 쓰는 다른 화면 (회귀 위험)
기존 테스트    스토리북 스토리, 컴포넌트 테스트, E2E 스펙 유무
```

`재사용 범위` 를 반드시 확인한다. 공용 컴포넌트를 고치면 이슈와 무관한 화면이 깨진다.

## 3. 자주 나오는 원인 유형

```text
증상                      먼저 볼 곳
------------------------  --------------------------------------
active/selected 안 맞음    비교 대상 타입 불일치(문자열 vs 숫자), 인덱스 기준 비교
깜빡임·레이아웃 점프       로딩 스켈레톤 높이, 이미지 크기 미지정
값이 갱신 안 됨            쿼리 키 누락, 캐시 무효화 빠짐, useEffect 의존성
모바일에서만 깨짐          미디어쿼리 분기, 고정 px, safe-area
빈 화면·에러 바운더리      옵셔널 체이닝 누락, 배열 기대에 null 도착
번역 누락                  i18n 키 미등록, 네임스페이스 prefetch 누락
```

## 4. 계획에 넣을 것

- 변경 파일 목록과 각 파일에서 무엇을 바꿀지 한 줄씩
- 회귀 위험 화면 목록
- 검증 명령 (저장소의 실제 스크립트를 확인해서 특정)

```bash
# 예시. package.json 을 읽고 실제 이름으로 바꾼다
npm run lint && npm run type-check && npm run build
npx playwright test <관련 스펙>
```
