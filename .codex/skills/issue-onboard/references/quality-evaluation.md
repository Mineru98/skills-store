# issue-onboard V2 필드 품질 평가

고정된 2개 라벨 fixture에서 `problem`과 `scope`를 평가했다. 결과는 각각 정확도 1.00,
재현율 1.00, unknown 비율 0.00 및 0.50이다. 표본이 작으므로 이 수치는 자동 차단 임계값을
정당화하지 않는다. 따라서 duplicate score는 후보 검색에만 쓰고, 네 조건의 명시적 일치와
GitHub 승인 결정 없이는 등록을 막거나 관계를 만들지 않는다.

검토 승인 기록: 이 문서는 구현 검토자가 결과·표본 확대 기준을 검토할 때의 기준본이다.
프로덕션 자동 차단 승인 전에는 최소 300 pair의 잠금 holdout에서 precision 95% 이상,
known false block 0건을 만족해야 한다.

2026-08-12: 요청자가 이 보수적 정책과 평가 기준을 승인했다. 이 승인은 자동 차단 승인이 아니며,
holdout 게이트를 통과할 때까지 `review-or-create` 흐름을 유지한다.
